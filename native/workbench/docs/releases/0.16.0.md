# Native Workbench 0.16.0

**Development prerelease.** Exact package validation and remaining limits are recorded below.

This development prerelease brings together the work developed after 0.11.0:
readiness and diagnostics, sample batches and queues, reusable indexes, verified
restart and resource scheduling, portable projects, reference management, and
curated training workflows with native results summaries.

## What is new

- **Curated training workflows:** alignment with QC and variant calling, using
  small bundled synthetic inputs. Review exact tool requirements and expected
  answers before explicitly loading a workflow. Missing dependencies identify
  the exact required version.
- **Native results:** search recorded analyses by name, sample, tool or status;
  inspect recorded SAMtools/BCFtools measurements, provenance and actionable
  failure guidance. Changed or unavailable evidence stays unavailable. Workbench
  does not invent sample QC pass thresholds.
- **Readiness and diagnostics:** review preparation checks and deferred work
  before execution; inspect local timing/resource records and explicitly review
  a bounded diagnostic export. There are no automatic diagnostic uploads.
- **Samples, queues and indexes:** map CSV/TSV sample columns explicitly, preview
  independent analyses or supported combined reports, and queue frozen plans.
  Reuse verified minimap2 short-read indexes with the additional align 0.4.1 pack.
- **Recovery and portable projects:** restart from verified completed steps;
  schedule ready independent steps within declared CPU admission budgets; export
  and import projects with exact dependencies, provenance and explicit same-byte
  input mapping. This is not within-tool checkpointing or a hard operating-system
  CPU cap.
- **Reference management:** resume verified downloads, review local-reference
  imports, relocate the library through copy/verify operations, and discover NCBI
  RefSeq assemblies alongside the existing Ensembl archive provider. Analysis
  continues to consume explicit local inputs.
- **Pack self-check paths:** additional pack workflows now run beside their
  installation-check report directory. Removing 37 characters of unnecessary
  nesting fixes the validated long-result-path case while retaining report and
  output provenance. Native child working directories of 260 characters or more
  remain unsupported.

The original bundled example, standalone tool mode, saved workflow pins and
expandable tool library remain available. Existing published tool-pack bytes and
the 32-pack setup profile/publisher trust are unchanged.

## Downloads and installation

The
[release page](https://github.com/comparativechrono/workbench/releases/tag/app-v0.16.0)
provides these archives and their matching validation/source evidence.

- [Windows Starter ZIP](https://github.com/comparativechrono/workbench/releases/download/app-v0.16.0/native-workbench-0.16.0-starter-windows.zip), **17,846,873 bytes**. Extract into a new folder and run `NativeWorkbench.exe`. No older installation is needed.
- [Updater from 0.11.0](https://github.com/comparativechrono/workbench/releases/download/app-v0.16.0/native-workbench-0.16.0-update-from-0.11.0.zip), **13,199,905 bytes**.
- [Matching application source](https://github.com/comparativechrono/workbench/releases/download/app-v0.16.0/native-workbench-0.16.0-source.zip), **47,848,425 bytes**.
- [Additional align 0.4.1 pack](https://github.com/comparativechrono/workbench/releases/download/app-v0.16.0/native-workbench-pack-align-0.4.1.zip), **575,862 bytes**, for explicit offline import where it is not already installed.

For an existing **published 0.11.0** installation, close Workbench, extract the
updater outside the application folder, run `UpdateWorkbench.exe`, and select
the existing `native-workbench` folder. The updater changes core application
files and preserves installed packs, saved settings, exact workflow pins, setup
state, existing results and local/external references. Do not overlay the Starter
onto an existing installation. The native update/verification path passed; the interactive folder picker was not exercised. This updater does not target the unpublished
0.12–0.15 tester candidates or older published versions.

A fresh Starter includes the original align/bam/variants 0.4.0 packs and the
additional align 0.4.1 pack side by side. The updater does not silently install
that additional pack. After updating, import its ZIP through **Manage tools →
Import pack ZIP** when reusable-index workflows need it. Full/Custom setup still
uses the unchanged published profile. Saved workflows retain their exact pins;
the curated training workflows use the published 0.4.0 packs.

Normal application use requires neither Docker, WSL, a browser nor system Python.
The optional pack ZIP is checksummed; offline import does not authenticate a new
publisher merely from that checksum.

## Scope and limits

This is a development prerelease for research and teaching. Synthetic known
answers establish the stated fixture behavior, not biological or clinical
validation, realistic workload capacity or a Windows–Linux performance claim.

Representative-PC, high-DPI, multi-monitor and physical-trackpad acceptance,
scientific Linux CWL validation, realistic benchmarking, executable signing and
institutional deployment remain separate outstanding work. Existing endpoint
security policies still apply. Hosted checks do not establish institutional
approval.

The legacy library capture helper emitted ignored control-enumeration warnings;
functional assertions passed, and final new-feature captures were reviewed separately.
Offline host checks deny Python socket operations; native
subprocesses are not described as operating-system-firewalled. Full downloads of
all 32 optional packs were not repeated, and unchanged optional scientific tools
were not all revalidated for this application release.
