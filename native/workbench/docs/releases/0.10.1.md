# Native Workbench 0.10.1

This
Windows x86-64 patch addresses Tool Setup navigation and repeated repainting,
and makes download failures more useful to diagnose. Published 0.10.0 and all
published tool-pack bytes remain unchanged.

## Tool Setup changes

The package list stays available for scrolling and inspection during catalogue
refresh and installation. Selection changes remain locked while an operation
is active. Previously, disabling the entire list also disabled navigation.

Changed row cells and controls are updated in place, preserving the list's
selection, focus and scroll position. Redundant text, progress, radio-button and
column updates are suppressed. The setup window no longer adds compositing
around its already double-buffered list. The previous release's unstable header
pixels and disabled navigation were independently reproduced on hosted Windows;
the exact patch candidate passes those checks under the same tested conditions.
Confirmation on the testers' physical displays remains separate.

Download failures distinguish HTTP status, proxy authentication, certificate/TLS,
DNS and connection problems from local storage failures such as insufficient
space, denied write access or a locked file. Messages expose bounded diagnostic
details and approved hostnames, without raw exception text, signed download
URLs or proxy credentials. Failure, cancellation and interrupted-operation
notices retain the affected pack name.

The reported download failure on the testers' PC **has not been reproduced or
diagnosed**. Both the previous and patched downloader retrieved the official
signed catalogue and a small real pack in the development environment. The new
diagnostics do not establish that the testers' download problem is fixed.

If installation fails after updating, record the
pack name and exact new message. Follow its specific next step: check writable
storage/free space for a local-file error, or ask the network administrator
about the named host and reported proxy/TLS/access error. Then use **Retry**
after the cause is addressed. A persistent error should be reported with that
pack name and message so the machine-specific failure can be investigated.
Completed packs remain installed; Retry restarts unfinished archives rather
than resuming a partially downloaded file.

The official publisher key, signed catalogue policy, approved hosts, pack
hashes and Full/Starter/Custom selections are unchanged. The bundled README now
correctly states that the production catalogue configuration is included.
Normal application use still needs no browser, Docker, WSL or system Python.

**161 source tests passed on Linux with one Windows-only skip**. The separate

Reports and the final native screenshot have been reviewed. The exact packaged
candidate passed these checks in both ordinary and space-containing Windows
paths:

In both negative controls, the previous package produced changing header pixels:
two or three distinct idle-frame hashes and three active-frame hashes. Its list
was disabled, wheel input left the top row unchanged at 25, and polling reset
the viewport or selection. This independently reproduces the regressions within
the hosted test conditions.

The patch produced one identical header-pixel hash across **192 ordinary-path
frames and 199 space-path frames**, sampling three seconds idle, two seconds of
wheel navigation and five seconds busy. Each path included 98 busy frames over
approximately 4.96 seconds. Wheel input moved the top row from 25 to 16 while
retaining selected and focused row 31; the list stayed enabled and polling did
not reset its viewport. Real scrollbar navigation was also exercised. These
finite desktop samples establish the correction in the tested conditions;
they do not cover every physical display, DPI setting or input device.

The real production **Full installation passed four checks** with unchanged
packaged trust: all 32 exact pack versions installed, reopened offline, retained
the expected 202-record alignment/BAM result and exposed the BED workflow input.
This validates installation/coexistence and starter scientific behavior, not
every optional pack scientific fixture. References explicitly omitted its
optional embedded updater helper; the separate 13-check updater passed.

The testers' network failure remains undiagnosed. Hosted checks do not establish
behavior under every institutional proxy or access policy. No new tester
acceptance is asserted. The release workflow promotes the accepted archives
without rebuilding and verifies public downloads; its receipt records publication.

The first candidate run failed its new UI probe because the validator posted a
key without restoring actual list focus. That failure remains diagnostic
evidence; its other passes do not establish acceptance of this candidate. The
[patch handover](../../knowledge/tool-setup-0.10.1-handover.md) records the source
checks, failed attempt, corrected probe and release evidence.
