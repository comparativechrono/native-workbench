# Native Workbench 0.11.0

Version 0.11.0 adds expandable native tool categories. Click a category to show
its tools; several categories can stay open. Search reveals matching tools and
clearing it restores the browsing state. Tool names retain their scientific
program names. Installed packs supply their own categories.

Tools mode opens a selected tool's standalone options. Workflow mode preserves
Add, double-click and drag-and-drop behavior. Category navigation never adds a
workflow step. Keyboard arrows and Enter/Space provide category navigation.

For an existing **0.10.1** installation, close Workbench, extract the updater
outside the application folder, run `UpdateWorkbench.exe`, and select the
existing `native-workbench` folder. Installed packs, saved settings, workflow
pins, setup state, results and local/external reference files are retained.
Do not overlay the Starter onto an existing installation.
From 0.10.0, first use the [0.10.1 updater](https://github.com/comparativechrono/workbench/releases/tag/app-v0.10.1).

The Starter includes minimap2, SAMtools and BCFtools. Full/Custom setup and
independently versioned packs remain available. Normal operation requires
neither Docker, WSL, a browser nor system Python.

## Scope and limits

Hosted Windows observations were at 96 DPI. Physical trackpad pinch,
high-DPI/multi-monitor operation, native updater folder-picker interaction and
institutional security approval were not established. The separate reported
Heimdal bridge block remains an organisation approval matter.

All 32 pack downloads were not repeated for this UI release; published pack
bytes and production trust/profile remain unchanged. Live Ensembl downloads
were repeated. References' optional embedded updater check was explicitly
omitted; the separate 0.10.1 updater gate supplies upgrade evidence.

Exported CWL was replayed through its embedded runner; this is not a new claim
of Windows `cwltool` execution. External CWL use still requires its documented
engine, Python, matching tool packs and inputs. These dependencies are not
added to normal Workbench operation.
