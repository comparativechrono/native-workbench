# Native Workbench 0.8.0

**Development prerelease — native Windows x86-64.** This release introduces the
accepted three-pane interface and clearer workflow inputs, with fixes for
scrolling, tool management and deeply nested pipeline results. Analysis remains
local, using bundled private runtimes; no browser, Docker, WSL or system Python
is required.

## Downloads

- [Windows starter](https://github.com/comparativechrono/workbench/releases/download/app-v0.8.0/native-workbench-0.8.0-starter-windows.zip): extract into a separate folder and run `NativeWorkbench.exe`.
- [Updater from 0.6.0](https://github.com/comparativechrono/workbench/releases/download/app-v0.8.0/native-workbench-0.8.0-update-from-0.6.0.zip): close Workbench, extract the updater outside the existing installation, then run `UpdateWorkbench.exe`.
- [Matching source and recovery materials](https://github.com/comparativechrono/workbench/releases/download/app-v0.8.0/native-workbench-0.8.0-source.zip).
- [SHA-256 checksums](https://github.com/comparativechrono/workbench/releases/download/app-v0.8.0/SHA256SUMS.txt).

**The updater requires an existing 0.6.0 installation. It does not support
upgrading 0.7.0.** For a separate 0.8.0 installation, retain the existing folder
and its data; extracting the starter does not migrate them automatically.

The starter includes three packs: minimap2 (`align`), SAMtools (`bam`) and
BCFtools (`variants`). The existing collection of **32 independently installable
tool packs** remains unchanged; additional packs install through
**Manage tools → Import pack ZIP**, including offline. Pack versions and saved
pipeline pins remain independent of the application version.

## Changes

- **Tools mode:** a searchable tool library on the left, the selected tool's
  inputs/options in the centre, and General settings on the right. Tool settings
  and the workflow keep independent edits while the application is open.
- **Workflow mode:** drag tools onto the canvas and add named, reusable input
  cards. Available input choices follow installed pack metadata. Bind files to
  their input card once, then connect them to compatible tool ports; paired
  reads retain separate read-1/read-2 fields. New tools start unconnected.
- Drag connections or use the named-source picker. Compatibility checks retain
  semantic types, required state, capacity and cycle rules. Pan the canvas, use
  zoom controls or Ctrl+wheel, and remove cards with hover controls or Delete;
  Undo restores removal.
- Tool names identify the scientific program. Initial **Manage tools** opening,
  scrolling repaint and small wheel movements are corrected. Nested result
  paths no longer fail the tested starter pipeline because of Windows' ordinary
  path limit; the application does not change machine policy.

The **References** feature introduced in 0.7.0 remains available: explicit
release-pinned Ensembl archive downloads for genome FASTA, GTF, cDNA, ncRNA and
protein, compatible input selection and offline local reuse. Species, assembly,
release, source and exact hashes remain in reference provenance and run methods.
Saved settings, pinned workflows, branching/shared outputs and result evidence
remain supported.

## Validation and scope

The project owner reported tester acceptance and authorized publication. The
accepted package was built from
[`b3928ca6a29d22b5f010a303658c2e19c24324da`](https://github.com/comparativechrono/workbench/commit/b3928ca6a29d22b5f010a303658c2e19c24324da).
[Candidate run 37453380541](https://github.com/comparativechrono/workbench/actions/runs/37453380541)
passed 82 source checks and, on Windows Server 2022 at 96 DPI, **32 workspace
checks plus eight References/update checks in each ordinary and space-containing
installation path**, with no failures or skips. References checks include real
GUI download/cancel actions, pinned hashes, offline reuse and provenance. The
0.6.0-to-0.8.0 updater preserved 187 existing files, verified 68 core files and
repeated idempotently.

A separate native regression completed all five starter scientific stages with
long-path opt-in disabled, independently verified 20 outputs and recovered the
expected variant. Scrolling checks observed 960 frames and 300 requested
transitions, with no unexpected sampled static-text/background frames; all 18
precision-wheel cases passed. CI did not reproduce the prior visual flashing,
so these finite samples are distinct from reported tester acceptance.

This is not a universal long-path or display guarantee. Physical trackpad pinch,
high-DPI/multiple-monitor behavior, native folder-picker interactions and
large-dataset performance remain outside the recorded automated scope.
Build provenance and source archives retain their creation-time candidate
status; separate release evidence records subsequent public-download and
exact-final checks without changing the accepted archives.
